# AI Sentiment Analyzer

An AI-powered conversation intelligence platform that analyzes customer support transcripts.

## Features
- TXT file upload
- Sentence-level sentiment analysis
- Overall sentiment detection
- FastAPI backend
- Next.js frontend
- AI-powered NLP analysis

## Tech Stack
- Next.js
- FastAPI
- Transformers
- Tailwind CSS

## Architecture
Frontend → FastAPI → NLP Model

## Run Locally

### Frontend
npm install
npm run dev

### Backend
uvicorn main:app --reload
